Each case runs the worker's own path. Teire fetches the repository, assesses it (registries, API diff, locate), runs the fix with each model as the agent, and verifies in the Cloudflare sandbox, the repository's own checks before and after. Every repository is public in [github.com/teire-dev](https://github.com/teire-dev), with tests that pass on the old version.

The columns read evidence · attempts · agent steps · model cost.

## Reading the diffs

Verified is necessary, not sufficient, so every patch was also read.

- **Super passed by bypassing the model.** On demo-py-agent it removed `temperature=0` and added a keyword rule: `if any(word in ticket for word in ["charge", "invoice", …]): return "billing"`. The tests passed because the rule classified without the model. **Ultra** instead raised `max_tokens` to make room for the reasoning model's answer.
- **Both widened a schema.** On zod, both models wrote `z.record(z.string(), z.unknown())` (or `z.any()`), where the faithful zod 4 form is `z.record(z.string(), z.string())`. No test caught it.

Teire added a **review** step for this. After a fix passes, Nemotron reads the final diff against the quoted notes and the rules. It flags changed behaviour, widened validators, weakened tests and ignored replacements, and sends them back to the agent once. On the rerun, the review caught Ultra's widened zod schema. The next attempt wrote `z.record(z.string(), z.string())` and verified. Review points never decide ready or draft: evidence does.

## What the evaluation fixed

Each bug below was found by a failing case, fixed, and the case rerun:

| Symptom | Cause | Fix |
|---|---|---|
| The `openai` Python SDK: 0 sites, then 4 failed attempts | griffe and jedi named re-exported classes differently | the join follows re-exports to the end; verified in 1 attempt, $0.036 |
| The Go major: Ultra regressed after 4 attempts, $0.60 | the docs tool pointed the agent at a path `read_file` refuses | `lookup_docs` answers with the target module's declarations; verified in 1 attempt, $0.145 |
| Kotlin: typecheck only after a passing fix | Gradle marked the unchanged test task up to date and printed no counts | test tasks always run |
| The AI web case: environment mismatch after 4 attempts | the baseline's install failed once, by chance | one retry of the baseline install; without a baseline the run stops before the agent |
| A retried sandbox start: `409 already running` | the first start was still running | a repeated start for the same run waits for the first |

## The pass bar

The plan set the bar as "Ultra ≥ Super on fixes, and the false-positive rate is recorded".

- **Ultra:** every fix verified and correct on reading.
- **Super:** every fix verified, one rejected on reading.
- **False positives:** none, across six clean repositories.

Super costs 3 to 7 times less per run and stays the failover.

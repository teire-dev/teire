A public scan runs the same assessment as an installed repository. It reads every dependency, every API host and model ID, and the runtime pins. It asks for no repository access and writes nothing to GitHub.

## Limits

| | Public scans |
|---|---|
| Who | Anyone signed in with GitHub. Reports and runs of public repositories can be read without signing in |
| How many | **3** scans and **1** dry run per person, over a rolling 24 hours |
| Which repositories | Public ones, up to **300 MB** as GitHub reports their size |
| What is read | The default branch at its latest commit, with the repository's own `teire.yml` |
| GitHub access | Your own sign-in token, read only, so your rate limit applies; anonymous when that fails |

## The report

The report page updates by itself while the scan runs. Most repositories take one to five minutes. A finished report shows:

- **Dependencies read**, per ecosystem as direct · transitive, with the files searched and how the lines were resolved (type-level or syntax-level),
- **Deadlines**: dated changes that reach the code,
- **Affected**: each change with its call sites linked to the exact line at the scanned commit,
- **Needs a person**: changes Teire could not decide alone,
- **Checked, not reaching this code**: changes Teire looked at and ruled out.

## Dry-run a fix

On an affected change, **Dry-run a fix** runs the whole fix as an installed repository would:

1. the upgrade or model swap,
2. the Nemotron agent, when the swap or upgrade alone does not pass,
3. your checks in two sandboxes, before and after,
4. the review of a passing agent fix.

Nothing is written to GitHub. The run page shows each step live and keeps the pull request Teire would have opened. Runtime notices have no dry run, because Teire does not change runtimes.

The run page has five tabs:

| Tab | Shows |
|---|---|
| **Timeline** | Every step as it happens, updated each second while the run is live |
| **Diff** | The code change, file by file |
| **Verification** | Each check's command and result on the baseline and after |
| **Receipt** | Model calls summed per model (count, tokens, cost), each sandbox command with its exit code and time, and the total |
| **The PR** | The pull request (or the "needs a human" issue) Teire would open once installed |

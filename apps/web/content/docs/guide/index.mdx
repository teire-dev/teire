Teire watches every dependency and API your repository uses: six package ecosystems, the AI and payment APIs your code calls, and the runtimes it is pinned to. When a change reaches your code, Teire finds the exact lines, NVIDIA Nemotron 3 Ultra on Nebius Token Factory edits what a plain swap cannot, your own checks run before and after in a sandbox, and the pull request shows the evidence.

## One change, end to end

The flow above, step by step, from Teire's evaluation on [teire-dev/examples/wrapped-models](https://github.com/teire-dev/examples/tree/main/wrapped-models).

<Accordions type="multiple">
<Accordion title="Notice">

`groq-sdk` is installed and Teire has no hand-written reader for Groq. The SDK's own published code names `api.groq.com`. Groq's `llms.txt` and a Tavily search led to `console.groq.com/docs/deprecations`. Nemotron read that page into change records, and each record was kept only because its quote appears word for word in the fetched page.

</Accordion>
<Accordion title="Impact">

`llama-3.1-8b-instant` sits in `src/models.ts:7` as `TIERS.quick.id`, not as a `model:` argument, so plain text search can't tell whether it reaches a request. Nemotron traced it: *"src/llm.ts:12 `model: t.id,`"*. Code then checked that the cited line exists in a file the model was shown and names a model. Only then did the finding become **affected**.

</Accordion>
<Accordion title="Fix">

Teire swapped `llama-3.1-8b-instant` for the one replacement Groq names. For `llama-3.3-70b-versatile` Groq names two, so Nemotron 3 Ultra chose `openai/gpt-oss-120b`. It also raised the quick tier's token limit so the new model has room to answer: 1 attempt, 12 steps, $0.095.

</Accordion>
<Accordion title="Verify">

Both sides ran in their own sandbox with the network off. The baseline's tests passed 0/4, because the retired models are gone. After the change, 4/4 passed.

</Accordion>
<Accordion title="Pull request">

The evidence was `verified`, so the PR Teire composed is a ready one that opens with **Verified.** It carries the quotes, the call sites, the before/after table and the receipt.

</Accordion>
</Accordions>

## What it reads

Six package ecosystems, each diffed with a tool built for its language:

<EcosystemGrid />

The APIs your code calls. These providers have a reader written for their change pages. Any other API host in your code or your SDKs is discovered and read by Nemotron under the same quote rule ([Providers](/docs/ecosystems/providers)).

<ProviderRow />

Node.js and Python runtimes are checked against their end-of-life dates. Those are notices only, never PRs ([Runtimes](/docs/ecosystems/runtimes)).

## What Teire never does

- Push to your default branch or merge anything. Every change goes to a `teire/…` branch in a pull request.
- Run your code outside a sandbox. Your checks run there with the network off.
- Send your code to any model but NVIDIA Nemotron on Nebius Token Factory.
- Act on a provider's change unless its quote matches the page it came from.

# Fixtures

Real files captured from upstream sources for Teire's tests. Catalog fixtures are short excerpts of provider pages, kept only to test the readers that parse those pages; each test names the live URL it mirrors. Do not edit fixtures by hand: re-capture them from the source.

`locate/major` and `locate/clean` are the sources of `teire-dev/examples/npm-major` and `teire-dev/examples/clean` (openai 4.104.0), used to test locating changed symbols and the verdicts.
